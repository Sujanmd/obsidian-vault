### What We Have Implemented

1. **`slate_facts.py` (M2-A — Completed & Tested)**
    
    - Parses `components.video[0]` from the channel YAML using PyYAML `BaseLoader`.
        
    - Enforces type grammar rules: strict integer syntax (no leading zeroes) and fraction parsing `N/D` for frame rates.
        
    - Validates mint preconditions: codec (`h264`), even width/height, bitrate budget range ($500{,}000$ to $100{,}000{,}000$), and aspect ratio validity (`16:9`, `4:3`, or `21:9`).
        
    - Proper exit codes:
        
        - `0`: Fully mintable (prints `size=`, `fps=`, `aspect=`, `bitrate=`).
            
        - `3`: Readable but non-mintable (prints `size=` and `fps=`; dumps all validation errors to stderr simultaneously).
            
        - `1`: Unreadable/malformed YAML.
            
        - `2`: CLI usage errors.
            
    - Passing unit tests (`TestSlateFacts` / TC-001–003).
        
2. **`check_slate.py` (M2-B — Completed & Tested)**
    
    - **SAR / VUI parsing:** Implemented SPS VUI parsing to extract `aspect_ratio_idc` via standard Table E-1 lookups and 32-bit Extended SAR (`sar_width` / `sar_height`).
        
    - **`--aspect A:B`:** Added display aspect ratio verification based on coded dimensions and parsed SAR.
        
    - **`--frames N`:** Verifies the stream contains exactly $N$ frames.
        
    - **`--budget BPS`:** Enforces the per-frame elementary-stream byte cap ($T = \lfloor 0.99 \cdot B \rfloor \times D / (8 \times N)$).
        
    - **Frame size calculation fix:** Fixed elementary stream measurement to measure pure H.264 NAL bytes (`es[hdr:]`) without counting the 14-byte PES packet wrapper.
        
    - Passing unit tests (`TestCheckSlate`).
        
3. **`make_slate.sh` (M2-C — Functionally Updated)**
    
    - Produces Constrained Baseline profile (Level 3.1) with AUD markers (`aud=1`).
        
    - Supports `--aspect` (defaults to simplified `width:height` if $16:9$, $4:3$, or $21:9$) and calculates SAR via `-vf "setsar=..."`.
        
    - Supports `--bitrate` for CBR padding using single-frame VBV buffer sizing (`-bufsize "${BUF}"` with `filler=1:vbv-init=1`), preventing frame-0 overshoots.
        
    - macOS / Bash 3.2 compatibility: removed unbound array expansion on empty `TIMEOUT_CMD`.
        
    - Atomic replacement: mints into a temporary file, executes `check_slate.py --strict`, and moves to `--out` only upon verification success.

### Summary of Changes

Implemented slate minting and validation tooling for the PRP assembler debug image in compliance with `assembler/specs/media-pipeline/slate.spec.md` (ADR 0063 / B-SLATE-1..5):

1. **`slate_facts.py` (New):**
   - Parses `components.video[0]` from the channel YAML using PyYAML's `BaseLoader`.
   - Enforces strict config grammar (non-zero leading integers, fraction `N/D` frame rates).
   - Validates B-SLATE-3 mint preconditions (H.264, even dimensions, budget within 500kbps–100Mbps, 16:9/4:3/21:9 aspect ratios).
   - Exit codes: `0` (mintable), `3` (readable but non-mintable; lists all errors on stderr), `1` (malformed YAML), `2` (CLI usage).

2. **`check_slate.py` (Updated):**
   - Added `--frames N` verification.
   - Added `--aspect A:B` support by decoding SPS VUI parameters (`aspect_ratio_idc` and Extended SAR).
   - Added `--budget BPS` to verify elementary stream frame sizes against $T = \lfloor 0.99 \cdot B \rfloor \times D / (8 \times N)$.
   - Fixed ES byte measurement by excluding the 14-byte PES header wrapper (`es[hdr:]`).

3. **`make_slate.sh` (Updated):**
   - Encodes Constrained Baseline profile (Level 3.1) with AUD markers (`aud=1`).
   - Supports `--aspect` and sets SAR via `setsar` video filter.
   - Adds CBR filler padding using single-frame VBV buffer sizing (`-bufsize "${BUF}"` with `filler=1:vbv-init=1`), preventing frame-0 overshoots.
   - Implements atomic creation: encodes to a temporary file, runs `check_slate.py --strict`, and renames only upon validation success.

4. **`boot_slate.sh` (New):**
   - Implements B-SLATE-1 boot orchestration: extracts facts $\rightarrow$ validates mounted asset (non-strict) $\rightarrow$ mints on-demand if mintable $\rightarrow$ falls back cleanly.
   - Fail-soft guarantees: logs diagnostic lines with `slate:` prefix to stderr, prints selected path or nothing to stdout, and exits `0` on any runtime issue.

5. **Test & Build Integration:**
   - Added `test_slate_tools.py` covering TC-ASM-SLATE-001 through TC-ASM-SLATE-007 (10 passing tests).
   - Added `assembler/tools/slate/CMakeLists.txt` and wired into `assembler/CMakeLists.txt` for `ctest` automation.
