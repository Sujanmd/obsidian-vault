- **Updated Debug Values, Golden Snapshots & Docs:** Removed the required slate ConfigMap from `values-debug.yaml`, bumped `Chart.yaml` to `0.1.2`, regenerated all 7 golden templates (`rendered/*.yaml`), and updated the Helm `README.md`.
    
- **Added CI Verification (`TC-020`):** Added two new must-pass test fixtures (`debug-no-slate.yaml` and `debug-digest-no-slate.yaml`) and updated `helm-verify.sh` to verify debug tags render cleanly without a slate while prod tags still fail closed.
    

**2. Tardis-Compose Deployment (`assembler/deploy/tardis-compose`)**

- **Debug Profile Allowance:** Updated `deploy.sh` and `README.md` so `./configs/debug/slate.ts` is optional at `up` time (letting the debug container mint a matching slate at boot, while noting `aspect_ratio` is needed for SD channels).
    
- **Validation Preserved:** If `./configs/debug/slate.ts` _is_ present, `deploy.sh` still validates it with `check_slate.py` before boot, and `prod` continues to fail closed if `slate.ts` is missing or invalid.
    

**3. Local Integration Harness (`fcs_mimic`) & Boot Tooling Fix**

- **Added `SLATE_LAYOUT=none`:** Updated `fcs_mimic/run-local.sh` and `README.md` to support booting without a mounted `slate.ts` so we can test boot-time slate minting on debug images and exit-78 refusal on prod images.
    
- **Fixed Schema Parsing in `slate_facts.py`:** Caught and fixed a mismatch during integration testing where `slate_facts.py` looked for `bitrate` instead of the channel schema's `bitrate_budget_bps` key (and added support for integer `frame_rate` values like `25` alongside `N/D`).
    

**4. Integration & Gate Verification (`TC-ASM-SLATE-010..012` + `helm-verify.sh`)**

- **`TC-010` (Debug Mounted vs. Bad Slate):** Verified debug image uses a valid mounted slate (`30000/1001`) without minting, and replaces a mismatched-FPS slate (`25` fps) by minting a valid replacement at boot.
    
- **`TC-011` (Debug Unmounted SD Minting & Refusal):** Verified debug image mints a `720x576` @ `25` fps slate when `aspect_ratio: "4:3"` is set and enters `app.playing`, and fails closed with exit `78` when `aspect_ratio` is omitted on SD.
    
- **`TC-012` (Prod Unmounted Refusal) & Helm Gate:** Verified prod image without a slate exits `78` and `helm-verify.sh` passes with `0 failed`.
